开源仓库（最新版 / 更新日志 / 问题反馈）：<https://github.com/YuMioHane/Vka-QuestAwayAssistant>

放置挂机用的外部小工具。四个功能都能单独开关：换图循环、自动收箱、自动转化、自动存仓。

它不修改游戏文件、不改存档、不改网络协议，只是替你点游戏里本来就有的按钮、拖本来就能拖的格子。

---

## 一、能不能用

- **Windows 10 / 11，64 位**（Win7 / Win8 / 32 位系统跑不了，会闪退且不留日志）
- Steam 版 QuestAway（免费）
- **不需要安装 Python**：解释器和依赖都打包在文件夹里了
- 系统自带的「通用 C 运行库（UCRT）」必须在。Win10/11 原生有；GHOST 精简版可能被删，
  缺了会表现为「双击无反应」。装一次「Microsoft Visual C++ 2015-2022 运行库 x64」即可。

### 建议这样启动

双击 **`启动-自检.bat`**。它会先检查环境（是否完整解压、是否 64 位、系统库是否齐全），
通过后自动拉起程序；如果程序启动后立刻退出，它会把 `helper_error.log` 的内容直接打在窗口里。

不想用 bat 就直接双击 `QuestAwayHelper.exe`，效果一样，只是少了自检。

### 为什么是一个文件夹

本版是**绿色版**：解压后得到 `QuestAwayHelper` 文件夹，里面有 `QuestAwayHelper.exe` 和 `_internal`。

- 请**整个文件夹一起用**，不要把 exe 单独拎出来放到别处，否则会启动不了。
- 好处：启动快、不往系统临时目录解压、退出时不会有「Failed to remove temporary directory」的提示。
- 想放桌面可以给 exe 建个快捷方式，文件夹本身别动。
- 卸载就是删掉整个文件夹，不留垃圾。

## 二、第一次使用（四步）

**第 1 步：把游戏彻底关掉**

包括托盘里的图标。游戏开着的时候启动助手，是拿不到调试端口的，助手会连不上。

**第 2 步：解压后双击文件夹里的 `QuestAwayHelper.exe`**

首次运行，Windows 可能弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
（没有数字签名就会这样。杀软误报同理，加白名单即可。）

> 如果以前用过**单文件版**，退出时可能看到「Failed to remove temporary directory: ...\_MEIxxxxx」。
> 那是单文件版在清理自己的临时解压目录，不影响功能。换成本版（绿色文件夹版）就不会再出现。

**第 3 步：指定游戏路径**

窗口最上面一行会显示游戏路径：

- 如果已经自动认出（比如 `F:\Steam\steamapps\common\QuestAway\QuestAway.exe`），跳过这一步
- 没认出来就点 **「选游戏路径」**，找到你 Steam 库里的 `QuestAway.exe`

路径会记在 `%LOCALAPPDATA%\QuestAwayHelper\helper_config.json`，下次不用再选。

> 找不到游戏目录？Steam 库里右键 QuestAway → 管理 → 浏览本地文件，地址栏就是。

**第 4 步：点「一键启动游戏」，然后点「连接」**

助手会用带调试端口的方式启动游戏，等几秒，右上角变成 **「已连接」** 就好了。

如果提示「检测到 QuestAway 正在运行」，说明还有进程没退干净——回第 1 步。

## 三、四个功能怎么用

| 模块 | 作用 | 建议设置 |
|---|---|---|
| 1 换图循环 | 图A / 图B 来回切，每张停留 N 秒 | 填 `6:5` 和 `6:6`，停留 60 秒 |
| 2 自动收箱 | HUD 上出现宝箱就点掉（普通/白银/首领都收） | 检查间隔 6 秒 |
| 3 自动转化 | 右键逐个放 8 格（材料/装备可选）→ 点 ✦ 转化 | 间隔 120 秒 |
| 4 自动存仓 | 对背包物品**右键直接存入**仓库；勾了「材料」就同时存材料 | 间隔 60 秒，选普通/精良 |

| 5 自动分解 | 工作台切「♻ 分解」，右键放一批再点分解；对象可选装备/材料，装备可按稀有度筛选，**默认只分解背包内** | 间隔 180 秒 |

转化对象可在「材料 / 装备 / 材料+装备」之间切换。装备按 普通→精良→稀有→英雄→神话 依次尝试，
哪种凑够 8 件就转哪种；材料选仓库里存量最多的那种。

**关于物品移动**：助手**不使用任何拖拽，也不用「自动填入」**。
- 存仓/取回：右键（右键=直接存仓，右键仓库物品=直接取回）；
- 转化填格：对背包物品**逐个右键**放进立方体，放满 8 格再点 ✦ 转化。
执行存仓/取回前会先关掉工作台，避免右键被合成面板接管。

- 关卡格式是 `章:关`，比如第 6 章第 5 关写 `6:5`。
- 转化和存仓都能用下面的「一次」按钮先试一发，看日志确认没毛病再开自动。

## ⚠ 关于「自动转化」和「自动存仓」

**这两个是试验功能，会用真实动作处理你的真实物品，后果自负。**

- 转化会**消耗**物品，合成结果不可逆；
- 存仓会**移动**背包物品到仓库；
- 游戏改版、界面变动、识别偏差都可能让它判断失误；
- 第一次开这两个模块时，程序会弹窗让你确认一次。

它们不会碰的两类东西：**身上正在穿的装备、上锁的物品**（程序里硬拦：扫描阶段过滤 + 操作前二次校验）。

保险做法：先只勾一个品阶，用「转化一次 / 存仓一次」单发试一遍，确认日志和游戏里的结果对得上，再开自动。

## 四、两条红线（程序里写死的）

1. **身上正在穿的装备，永不移动、永不转化。**
2. **上锁的物品，永不移动、永不转化。**

扫描阶段就过滤掉，操作前还会用坐标再验一次源头，两道闸都过不了才动手。
日志里如果出现「已拦下 N 件（装备中/上锁，不碰）」，就是它在保护你的东西。

## 五、常见问题

**连不上 / 一直显示「未连上」**
- 十有八九游戏是从 Steam 直接启动的。必须**先关掉**，再用助手的「一键启动游戏」。
- 关掉助手重来一遍，顺序不要错。

**点了「一键启动游戏」但游戏没出来**
- Steam 客户端得开着（游戏要连 Steam）。
- 路径可能指错了，重新选一次。
- 弹「要求管理员权限」：关掉助手，右键「以管理员身份运行」，再点一次。
- 弹「系统拒绝（错误 5）」：杀毒软件拦了，把助手加白名单。
- 这些提示都会写在日志里，不会让程序直接退出。

**点开就消失、连日志都没有**
- 先确认是**解压后**运行的：在压缩包预览窗口里直接双击 exe，`_internal` 文件夹不在旁边，程序起不来。
- 解压路径别放在 `C:\Program Files`、别放在中文很长的目录、别放在 OneDrive 同步目录里。
- **系统是不是 Win7 / Win8？**本程序用的 Python 3.12 需要 Win10/11，老系统会在加载阶段直接退出，日志都来不及写。
- **是不是 32 位 Windows？**本程序是 64 位，32 位系统无法运行。
- 系统是否被 GHOST/精简过？缺 `ucrtbase.dll` 就装「Visual C++ 2015-2022 运行库 x64」。
- 杀软拦截也一样（连日志都不留）：把整个文件夹加入白名单。
- 用 `启动-自检.bat` 启动，它会把这三种情况和日志内容直接打在窗口里。
- 还不行就运行 `QuestAwayHelper_debug.exe`（诊断版），把黑窗口内容截图发作者。

**点了作者主页/链接，程序直接消失**
- 已修复：现在打不开浏览器会弹提示、并写日志，不会退出。
- 如果你用的是旧版，请换成本版。

**日志里说「立方体 8/8」但没转化**
- 主界面上的产出格里有上一批的成品，先把它取走。
- 或者游戏正在结算上一次转化，等两秒再看。

**自动收箱好像没反应**
- 宝箱出现是随机的，槽位没显示就是没有箱子，正常。
- 有箱子的那一瞬间助手会点，日志会打印「收箱：普通」。

**改了间隔想立刻生效**
- 直接改数字就行，助手每秒读一次配置，下一轮生效，不用重启。

**想换回 Steam 自己启动**
- 把助手关掉，然后从 Steam 正常启动游戏即可。调试端口不会再开着。

## 六、说明

- 只在你自己的账号上用。是否允许外部工具，请自己对照游戏的用户协议与 Steam 条款。
- 助手的操作会正常进入游戏的存档与结算上报，不会伪造任何数据。
- `helper_error.log` 就在 `QuestAwayHelper.exe` 同目录，每次启动都会写一行「=== 启动 ===」；
  出问题把这个文件发给作者即可。
- 配置在 `%LOCALAPPDATA%\QuestAwayHelper\helper_config.json`，删掉等于恢复默认。
